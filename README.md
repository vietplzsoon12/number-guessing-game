
# 🎮 Number Guessing Game

My first Python project!

A terminal-based number guessing game where the player
tries to guess a randomly generated number before
running out of attempts.

## Features

- Random number generation
- Easy, Medium, and Hard difficulties
- Hints after each guess
- Input validation
- High scores saved in JSON
- Interactive main menu

## How to Play

1. Install Python 3.
2. Run `python main.py` in the project folder.
3. Select Play Game.
4. Choose your difficulty.
5. Guess the number before running out of attempts!
